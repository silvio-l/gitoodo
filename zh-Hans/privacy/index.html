隐私说明：网站与手机应用

本页说明访问 Gitoodo 网站和使用手机应用时会处理哪些数据。桌面应用另有说明文档，见下文。本页以德文版本为准。

托管

本网站是静态网站，由 GitHub Inc.（美国）的 GitHub Pages 服务提供。打开页面时，GitHub 会处理技术上必需的访问数据：IP 地址、时间、请求的地址和浏览器标识。法律依据为 GDPR 第 6 条第 1 款 f 项（对网站可访问性的正当利益）。向美国传输数据受欧盟—美国数据隐私框架和标准合同条款（GDPR 第 46 条第 2 款 c 项）保障。字体、图片和脚本都由本网站自身提供，不使用 CDN。

下载

下载按钮指向 GitHub（github.com）上的安装程序。只有在你点击其中一个时，浏览器才会从 GitHub 下载文件；此时 GitHub 会获得你的 IP 地址和浏览器标识。法律依据是 GDPR 第 6 条第 1 款 (f) 项。页面本身在加载时不会向 GitHub 查询任何内容。

使用 Matomo 统计

为了了解谁在访问本网站、什么内容对他们有帮助，我们使用开源软件 Matomo。它会记录截去两个字节的 IP 地址、浏览器、操作系统、设备类型、屏幕分辨率和浏览器语言，由此推断的国家和地区，你来自哪个页面，链接中的推广参数（例如 utm_campaign），以及访问的页面及其语言、时间和停留时长。此外还记录不含任何内容的事件：点击下载、源代码、支持及其他按钮，切换语言，哪些区块出现在屏幕上，打开了哪些常见问题条目，视频是否被播放，是否发送了联系消息（仅记录其类别），以及技术性加载指标（Core Web Vitals）。

Matomo 运行在我们自己位于德国 netcup GmbH 的服务器（matomo.silvio-und-maik.de）上。数据不会提供给第三方。不建立用户画像，也不进行跨设备追踪；只做汇总分析。

Matomo 在这里不设置 Cookie，也不读取你设备上的任何内容。因此根据德国 TDDDG 第 25 条无需征得同意，也没有 Cookie 横幅。法律依据为 GDPR 第 6 条第 1 款 f 项，即我们按需改进网站和应用的正当利益。Matomo 不读取浏览器的“请勿跟踪”设置；你可以通过下方的选项提出反对。

原始数据在 180 天后删除。之后只保留不含个人数据的汇总报告。

你可以随时提出反对（GDPR 第 21 条）：取消勾选下方选项即可。为使反对生效，Matomo 会在你的浏览器中为本网站保存 Cookie mtm_consent_removed。删除它后，你的访问会再次被统计。

无法加载反对选项，例如因为 JavaScript 或 Matomo 的地址被拦截。只要这种情况持续，就不会记录任何数据。你也可以通过电子邮件提出反对。

联系表单

通过页面底部的圆形按钮，你可以给我们写信。只有在你点击“发送”后，浏览器才会把你的消息、所选类别、你填写的邮箱地址以及页面的语言和路径发送到我们的中继服务（relay.silvio-und-maik.de）。法律依据是 GDPR 第 6 条第 1 款 (b) 和 (f) 项：处理你的请求。

中继服务运行在德国 netcup GmbH 的服务器上，位于 Cloudflare 之后（流量经过 Cloudflare 的网络），并通过其邮件服务商把消息以电子邮件转发到我们的邮箱；你的邮箱地址会成为回复地址。中继服务不保存内容。为防止滥用，它会在一小时内按哈希后的 IP 地址统计请求次数，并只记录发送方标识、时间、编号、结果、大小，以及用每日更换的盐值计算的 IP 地址哈希；该日志在 14 天后删除。邮件会保留在我们的邮箱中，直到事情处理完毕。

浏览器存储

如果你在页眉或页面底部选择一种语言，网站会把这一选择保存在浏览器的本地存储中（gitoodo.site.language），下次首页会以该语言打开。该条目不会离开你的设备，是这项功能所必需的（TDDDG 第 25 条第 2 款第 2 项）。联系表单不会在你的浏览器中保存任何内容，只会记下你已看过或关闭了联系按钮旁的问候（gitoodo.site.contact.greeted），这样它不会每次访问都出现。你的草稿只在页面打开期间存在。如果你在页眉中选择“浅色”或“深色”，网站会将其保存在 gitoodo-theme 中，下次访问时页面会保持该外观；选择“跟随系统”会删除该条目。它同样不会离开你的设备，只用于这项功能。

应用

桌面应用与本网站相互独立。它无需账号，令牌保存在系统钥匙串中，并会向我们在欧盟的自有服务器发送匿名、无 Cookie 的使用统计：默认开启，绝不包含仓库名称、内容或令牌，并可随时关闭，在初次设置时或在“设置 → 通用”中均可。详情见应用的隐私说明文档。

应用隐私说明

手机应用

Gitoodo 的 iPhone 和 Android 手机应用（de.gitoodo.app.mobile）显示你自己的 Gitoodo 桌面应用中的问题，并把你的回答发回桌面应用。它不需要账号，不连接我们的任何服务器，也不含统计、广告或跟踪；Android 上的扫码组件会向 Google 报告哪些信息，见下文。我们不会通过这个应用获得你的任何数据。

你只需配对一次：扫描桌面应用显示的二维码；没有摄像头时，也可以输入二维码下方显示的地址。此后，应用只与这台电脑通信，而且只在本地网络内：它只接受本地网络地址，从不经过代理，每个请求都经过端到端加密（X25519、HKDF-SHA256、ChaCha20-Poly1305）。网络中的窃听者只能看到密文。系统会就访问本地网络询问你一次。传输的内容包括：你的电脑在“给我的问题”中列出的问题（含账号、仓库、编号、标题和内容）、你的回答、评论和操作，你的仓库列表及其自动驾驶状态和正在运行的会话，以及一个粗略的设备名称（例如“iPhone · App”），电脑用它来列出这部手机。桌面应用会以你的账号把回答作为评论发布到你的代码托管平台上，那里适用该平台的隐私政策。

应用在手机上只保存三样东西。配对信息（电脑的地址和名称、设备 ID 和密钥）保存在系统的安全存储中：iOS 上是钥匙串，不同步；Android 上用 Android Keystore 中的密钥加密。应用数据文件夹中的 seen.json 只记录已经显示过的条目的账号、仓库、编号和开始等待的时间，以免同一个问题提醒两次；其中没有标题或内容。此外，应用界面的存储会记下你是开启了通知还是选择以后再说（gitoodo.mobile.notify）。问题和回答只用于显示，应用不会长期保存。

应用只在扫描配对二维码时使用摄像头，而且要在你允许之后。图像在设备上处理，既不保存也不发送。在 iOS 上由系统本身识别二维码。在 Android 上由 Google ML Kit 通过 Google Play 服务完成；据 Google 说明（developers.google.com/ml-kit/android-data-disclosure），ML Kit 会把设备和应用信息、设备或安装标识符、性能指标和错误代码加密发送给 Google，用于诊断和使用情况分析。法律依据为 GDPR 第 6 条第 1 款 f 项（我们对可靠扫码功能的正当利益）。如果你不想使用摄像头，可以直接输入地址。

通知默认关闭，直到你在应用中开启并获得系统同意。通知在手机本地生成，应用不使用任何推送服务。开启期间，应用每 15 秒询问一次已配对的电脑是否有新问题。在 Android 上，一个带常驻通知的前台服务让它保持运行；在 iOS 上，只有在系统允许应用运行期间才会如此。通知会显示问题的标题、仓库和编号；锁屏上显示多少内容由你的系统设置决定。作为反馈的振动和提示音都在手机本地产生。

你可以从 Apple 的 App Store 或 Google Play 获取这个应用。下载时在那里产生的数据（账号、购买、安装）由 Apple 或 Google 作为独立的负责方，按其各自的隐私政策处理。如果你在系统设置中选择与开发者共享崩溃报告，应用商店可能会把这些报告提供给我们。

“在这部手机上取消配对”会删除手机上的配对信息；桌面应用设置中的“取消配对”会让它在电脑上失效。卸载应用时，系统会删除应用的数据；在 iOS 上，钥匙串中的条目可能在卸载后仍然保留，因此请先取消配对。
